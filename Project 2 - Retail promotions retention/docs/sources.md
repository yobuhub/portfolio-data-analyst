# Data sources

### dunnhumby - The Complete Journey dataset

- **Provider** - dunnhumby
- **Dataset** - The Complete Journey
- **Source** - <a href="https://www.dunnhumby.com/source-files/">original website available</a>
- **Acquisition date** - 11th of October, 2026
- **Scope & Period** - purchases of 2,500 households at one retailer within ~2 years
- **Documentation** - The Complete Journey User Guide (downloaded together with the set)

### Data access and usage

- **Redistibution** - source data is not available in this github repo on purpose
- **Reproduction** - own data copy can be accessed through the dunnhumby site → follow the [import guide](import_guide.md)
- **Licence** - not an open-data licence. Project code licence does not extend to the dataset

### Limitations

- **Sample bias** - households that shop frequently at one retailer. Cannot be generalized for the whole retail market.
- **Incomplete basket** - only purchases at this one retailer are observed. Households may also shop elsewhere, so some measures might be distorted.
- **Demographics** - information available for only part of the sample.
- **Causality** - associations between promotions and repeat purchases do not, by themselves, demonstrate a causal effect.
- **Time horizon** - data for a limited time period (i.e. ca. 2 years).
